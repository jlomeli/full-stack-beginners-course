# Course feature map

One file per thing a student or the instructor does with the repo. Each says how to reach it, how to drive it, and what proves it works.

| Feature | Who | File |
| --- | --- | --- |
| Run a lesson's tests from a lesson branch | Student, CI | [student-tests.md](student-tests.md) |
| Check starters fail and solutions pass | Instructor | [verify-solutions.md](verify-solutions.md) |
| Regenerate the syllabus from curriculum.json | Instructor | [curriculum-build.md](curriculum-build.md) |
| Run a lesson's API or page by hand | Student | [lesson-apps.md](lesson-apps.md) |
| Provision repos, list the review queue, show progress | Instructor | [class-sh.md](class-sh.md) |
